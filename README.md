# Zakir

Zakir is a React and TypeScript web project built with Vite, shadcn-ui, and Tailwind CSS. It uses a modern frontend stack to create a responsive, component-based website experience.

## Highlights

- Modern React application structure
- Responsive interface for desktop and mobile screens
- Component-driven UI using shadcn-ui
- Tailwind CSS styling for fast iteration and clean layout

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Run Locally

```bash
npm install
npm run dev
```

Then open the local development URL shown in your terminal.

## Project Focus

This project demonstrates a clean modern frontend setup and practical UI implementation using a stack that is suitable for client websites and business web apps.
